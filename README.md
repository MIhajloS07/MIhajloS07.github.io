## 📖 About the project

**FilmexTip** is a dynamic web application that loads movies from an external REST API in real time and displays them as responsive cards. Users can search for movies, open a details page for each one, and switch the site between **light** and **dark** themes.

The project was created as the practical part of the free online course **"Development of a Dynamic Website – JavaScript"**, delivered by **Singidunum University** for high school students. It demonstrates the core concepts of modern front-end development using plain (vanilla) JavaScript, with no frameworks.

> ℹ️ This is an original project built during the course, not a copy of someone else's solution.

## ✨ Features

| | Feature | Description |
|---|---|---|
| 🎞️ | **Dynamic movie loading** | Data is fetched from a REST API with `fetch()` and rendered without reloading the page |
| 🔍 | **Search** | Search via the *Search* button or automatically while typing |
| ⏱️ | **Debounced search** | The query is sent 600 ms after the last keystroke, avoiding unnecessary API calls |
| 🃏 | **Cards from an HTML `<template>`** | Each movie is generated by cloning a template (`cloneNode`) |
| 📄 | **Details page** | Poster, title, original title, director, runtime, release date, genres, actors and description |
| 🔗 | **Passing parameters via URL** | Details are loaded from `?p=<shortUrl>` using `URLSearchParams` |
| 🌗 | **Light / dark theme** | The choice is stored in `localStorage` and persists between visits |
| ⏳ | **Loading indicators** | Bootstrap *spinner-grow* animation while data is loading |
| 📱 | **Responsive design** | Works on phones, tablets and desktops thanks to the Bootstrap grid |
| 🗂️ | **Accordion and navigation** | Project info on the home page, collapsible navbar and an "About" page |

## 🛠️ Technologies

- **HTML5** – semantic page structure and the `<template>` element
- **CSS3** – additional styling in `css/styles.css`
- **JavaScript (ES6+)** – `fetch`, Promises, arrow functions, template literals, DOM manipulation, `localStorage`, `URLSearchParams`
- **[Bootstrap 5.3](https://getbootstrap.com/docs/5.3/getting-started/introduction/)** – grid, cards, navbar, accordion, spinners, built-in dark mode (`data-bs-theme`)
- **[Font Awesome 7](https://fontawesome.com/)** – icons
- **[Movie Cache API](https://github.com/Pequla/express-movie-cache)** – source of movie data (`https://movie.pequla.com/api/movie`)

## 🔌 API endpoints used

| Method | Endpoint | Purpose |
|---|---|---|
| `GET` | `https://movie.pequla.com/api/movie?search={query}` | List of movies (with optional search) |
| `GET` | `https://movie.pequla.com/api/movie/short/{shortUrl}` | Details of a single movie |

## 🚀 Running locally

The project is fully static, so no installation or build step is needed.

```bash
# 1. Clone the repository
git clone https://github.com/MIhajloS07/MIhajloS07.github.io.git

# 2. Enter the folder
cd MIhajloS07.github.io

# 3. Open index.html in your browser
#    (or use a local server, e.g. the VS Code "Live Server" extension)
```

An internet connection is required, since Bootstrap, Font Awesome and the movie data are loaded from external servers.
